# Create Adventured

A [Create](https://modrinth.com/project/LNytGWDc) inspired modpack with elements of adventuring.

Build factories, lay down railways, and then pack your backpack and head out to explore new structures, loot, and dungeons.

## Features

- **Automation & Engineering** — Create plus a large set of addons for decor, trains, farming, kitchens, and more.
- **Adventuring** — Extra structures, lootable containers, relics, artifacts, and backpacks for the road.
- **Cozy Survival** — Farmer's Delight, seasons, comforts, and handcrafted furniture.
- **Quality of Life** — EMI, Jade, Xaero's maps, inventory tweaks, and more.
- **Performance** — Sodium, Lithium, ModernFix, and friends keep things smooth.

## Setup

### Client

Install the pack through the Modrinth App, or import the `.mrpack` from the [Versions](https://modrinth.com/modpack/create-adventured/versions) page into any launcher that supports Modrinth packs.
